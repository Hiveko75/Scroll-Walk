# Scroll-Walk
Hold Alt and Scroll to dynamically adjust your movement speed.

## Hiveko build (Minecraft 26.1.x and 26.2)

- The walking speed key is a normal key binding, **Walking speed (hold + mouse wheel)** in Options → Controls →
  Key Binds (category Scroll Walk), Left Alt by default. The original reads Left and Right Alt directly, which
  cannot be changed and clashes with other mods that use Alt.
